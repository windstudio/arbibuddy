# 制品与证据

源码、测试、说明提交Git；安装树、wheel、ZIP、完整日志、密钥与测试产物放源码外受控目录。样本文书仅限已确认虚构且经属性核对的版本化测试夹具。

构建产物先暂存和校验。公开开发工具的目标目录由显式source根和VERSION确定为 `<source>/dist/<VERSION>`，只是候选构建规则；维护者的正式交付另按其已固定发布根办理，其他checkout不承担正式交付。本准备副本尚未批准第三方二进制分发。

发布清单、门禁报告、包、运行身份及各项SHA-256必须绑定同一对象；证据只读校验不执行测试、不创建包、不把历史结果升级为当前PASS。版本不一致、越界、符号链接或缺失证据须拒绝。完整失败/会话原件保留私有，公开有界摘要。
