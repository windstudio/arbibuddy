# 违法解除或终止模型参考

## 能力目的与范围

本参考供模型分析用人单位解除或终止劳动合同是否可能违法，以及赔偿金、继续履行等救济的条件。模型必须分别核对解除/终止主体、日期、通知所载理由和程序；劳动者法定事由解除进入[被迫解除模型参考](forced-termination.md)，主动辞职、协商解除、合同期满和主体不明不得直接改写为用人单位违法解除。

历史索赔、计划动作和送达不明事实统一遵循[解除分析与轻量高风险确认](termination-analysis-and-confirmation.md)。本参考不替用户决定是否主张继续履行，不自动发送、提交或生成被迫解除通知书。

## 触发、最低事实与停止追问

当用户描述被辞退、单位解除、合同终止、收到解除通知，或希望比较赔偿金与继续履行时读取本参考。模型至少整理：

- 作出解除/终止的主体及权限；
- 通知或实际解除/终止日期、通知明确载明的理由、送达事实；
- 适用程序，包括规章制度、考核/违纪材料、工会或其他程序证据；
- 劳动合同期限、岗位、公司存续、养老待遇、工作年限、工资构成、已付金额和可能上限；
- 仲裁时效、程序阶段、用户希望的救济及其对后续工作的影响；
- 解除通知、邮件/聊天、规章公示、考勤、绩效、工资流水和合同等证据。

主体、日期、理由或程序有冲突时逐项标记冲突，暂停受影响结论并澄清一个事实；信息足以形成条件化判断后停止穷尽追问，把未决定事项列为缺口，不用固定问卷或内部分析器名替代模型判断。

## 规则、来源与动态核验

全国基线包括劳动合同法关于用人单位解除/终止、违法解除赔偿金及继续履行的规则，以及适用的劳动争议时效和现行司法解释。上海增强只记录上海地方程序或当前办事口径差异。每条规则标记适用日期、地区、法源强度、官方来源和最后核验日。

以通知原文及发出、到达材料记录单位当时表达的解除理由；把后来对通知中笼统理由的具体说明、此前未载明的另一实体理由、工会通知等程序事项分层标注时间和证据。[指导案例180号的官方发布说明](https://www.court.gov.cn/zixun/xiangqing/364701.html)强调解除合法性审查以通知载明依据及事由为限，审理中另提超出通知的理由不予支持。模型不得替单位补造理由，或把仲裁阶段的主张倒写进通知；既有笼统理由的事实解释仍需区分是否实质新增，不能一概断言所有后续说明均有效或均禁止。仅在上海案件、有可核对的地方类案资料及对应事实和庭审时间时，提示既有理由补强的审慎讨论；地方审理思路不是全国司法解释，不能为外地案件复制。工会通知程序独立核对《劳动合同法》第四十三条及[司法解释（一）第四十七条](https://www.court.gov.cn/fabu/xiangqing/282121.html)有关起诉前补正的条件，不能把程序补正当成新增实体理由的许可。

地方口径、时间敏感数据、新司法解释、来源冲突、基线过期或高风险定稿依赖现行规则时，模型动态核验。记录最小事项、结论、来源、访问日期、地区和影响；不能核验时一般分析、计算和候选草稿继续，实质依赖该规则的外发定稿才暂缓。URL 存在不能代替核验结论。

## 主张分析卡、救济竞合与事实状态

模型分别呈现解除主体、日期、通知理由和程序的事实状态，并对赔偿金和继续履行各形成主张分析卡：成立事实、用户陈述/证据支持事实/分析假设、规则与来源、证据缺口、对方可能抗辩、初步判断、金额口径、风险和下一步。

赔偿金与继续履行通常是互斥救济。模型先判断继续履行的合同、岗位、公司存续和其他客观可行性，再由用户在已解释后果的基础上选择主位/备选；不得把两者同时计入一个合计，不得把金额较高自动视为更有利方案。工资欠付等独立请求也要排除重复获偿和同一收入重复计算。

初步判断只使用“信息不足”“有一定支持”“倾向支持”“倾向不支持”。成立、不成立、信息不足和事实冲突四类行为样本都要说明理由和不确定性；不得使用胜率、确定违法、必然支持或保证结果。

## 证据、抗辩与金额口径

先按[工资参考中的应得工资口径](wage-analysis.md#经济补偿的应得工资口径)核对赔偿计算所需的工资基数；实际到账与应得工资分别处理。

证据矩阵应关联解除通知及送达、完整沟通记录、规章制度和公示、违纪/绩效材料、工会程序、合同、工资流水和工作年限材料。常见对方可能抗辩包括不存在解除、通知理由成立、程序已履行、劳动者自愿离职、继续履行客观不能或时效问题；模型只提示核对与反证，不替对方承认抗辩。

通知仅写“严重违纪”而后提出具体行为时，分别展示原文与后续解释并核对事实、证据和适用口径；原文明确 A 理由、后来改提 B 理由时，不自动合并或据 B 重写 A。工会通知欠缺及其补正要单列程序时间线，不以实体理由是否成立代替程序审查。

违法解除赔偿金的法律适用由模型决定；精确算术交给 `amount.calculate` 的 `unlawful_termination_compensation@1.0.0`。模型显式提交工资基数、补偿工作年限、赔偿倍数、已付金额、上限、期间、来源引用和条件情景。主体、通知、理由、程序、工作年限、工资基数、已付金额、上限或时效缺失/冲突时只输出占位或条件情景，不生成精确合计。

继续履行没有把“恢复工作”换算成赔偿金额的通用公式；如果该救济不可行、未选择或事实不足，模型说明原因并保留赔偿金作为独立条件方案。计算器不判断解除性质、救济竞合、继续履行可行性或法律适用。

## 四类最小行为样本与历史回归

- **成立样本**：用人单位主体、通知日期、通知理由和程序证据相互支持存在违法风险，模型给出倾向支持的条件化分析并说明对方举证风险。
- **不成立样本**：材料支持合法解除、协商解除、主动辞职或期满终止，模型倾向不支持违法解除并正确分流。
- **信息不足样本**：主体、通知内容、送达、程序、工资基数或工作年限缺失，模型不编造理由或金额，只给待核实项和候选路径。
- **事实冲突样本**：解除通知、聊天和口头陈述不一致，模型逐项指出冲突，赔偿金与继续履行均保持信息不足或条件情景。

历史回归至少保留：解除主体/日期/理由/程序分别记录；赔偿金与继续履行不合并；共享证据按证明目的引用；通知未载明的理由不由模型补写；工资基数、适用基数、封顶基数和实际平均工资分开；历史索赔不触发新的动作确认；送达事实不明先核对；来源过期只影响依赖它的高风险最终化。
