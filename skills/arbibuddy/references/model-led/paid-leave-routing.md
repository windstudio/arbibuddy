# 其他法定带薪假：模型主导分层路由参考

本文件是婚假、产假、陪产假、育儿假、病假及其他法定带薪假的唯一模型可读参考。模型负责识别假种、地区、程序和待遇性质，形成路径卡、证据计划、交叉方案和自然语言解释；不把“未休假”自动改写为全国通用现金补偿。计算器只在模型已经把事实和法律口径分流为明确的工资/待遇差额项目时执行显式数学。

## 能力边界

- 路径状态至少区分：休假权（`leave_entitlement`）、工资或待遇差额（`wage_or_benefit_difference`）、行政处理（`administrative_handling`）、条件性交叉路由（`conditional_cross_route`）、信息不足、专业复核、待核验和有事实依据的排除。
- 未休年休假工资不归入本路由，使用 `annual-leave-pay` 独立参考；企业自设福利假也不能直接改写成全国法定现金请求。
- 产假必须分别识别休假权、产假工资、生育津贴和用人单位工资差额；生育津贴属于社会保险待遇路径时，不得直接包装成劳动报酬。
- 本路由不决定仲裁请求成立、不生成正式 Word，也不为所有假种自动生成精确金额；超出深度支持或地方规则不明时提供条件化路径和专业复核建议。

对应深度支持争议：社保/公积金与复杂争议保持分层处理；婚假、产假、陪产假、育儿假和病假主要提供路径识别、工资/待遇差额条件分析和证据准备，不把行政待遇与劳动报酬混同。

## 触发、最低必要事实与停止条件

用户提到具体带薪假、请假被拒、待遇未发、产假工资/生育津贴差额、病假工资或地方假期安排时触发。模型至少收集：

1. 具体假种和资格事实；
2. 劳动关系实际履行地及争议期间（跨月跨年应分段）；
3. 在职/解除/仲裁/诉讼程序阶段；
4. 请假申请、单位答复、安排和实际休假；
5. 工资、津贴、社会保险待遇和已付金额的性质与支付记录；
6. 用户目标：继续休假、补发工资待遇、行政处理或先核验路径。

事实足以区分权利、差额和行政处理时停止追问；地区、假种资格、待遇标准或程序口径缺失时，只提出一个最高价值问题并输出信息不足/待核验路径。不得用固定问卷、客户端分析器选择或脚本状态推进。

## 全国基线、上海增强与核验元数据

- 全国基线：`NAT-PAID-LEAVE-ROUTING-001@1.0.0`，最后核验日期 2026-08-01，法源强度为全国行政法规、医疗期规则与官方发布；源登记见 [`references/legal/paid-leave-routing-rules.v1.json`](../legal/paid-leave-routing-rules.v1.json)。
- 上海增强：上海婚假、生育假、配偶陪产假、育儿假和工资支付口径使用 `SRC-SH-FAMILY-PLANNING`、`SRC-SH-WAGE-PAYMENT`；北京样本只能使用北京来源。上海来源不得支持北京结论，反之亦然。地方规则、待遇标准和程序口径在案件中按适用地区和日期动态核验。
- 病假还要区分全国医疗期基线与地方工资支付口径；产假要区分全国女职工保护基线、生育保险待遇和单位工资差额。
- 官方 URL、复核日期和来源状态只是基线元数据；来源过期、冲突、地区不匹配或用户要求最新依据时，模型记录动态核验事项，不把登记存在误写为本案已核验。

## 事实、证据与分析假设

“用户陈述”“证据支持事实”“分析假设”必须分开。最低证据—证明目的矩阵包括：请假申请/安排、单位答复、考勤、工资条与银行流水、资格材料、社会保险待遇通知、合法取得的完整电子记录、地区/程序材料。合同、工资流水、社保记录和单位制度可在劳动关系、工资和带薪假路径中共享，但每张路径卡要注明各自证明目的和缺口。

常见抗辩或事实冲突包括假种资格不足、单位已安排、员工未实际休假、病假材料不足、工资中已包含某待遇、地区规则不适用、待遇应由社会保险支付或用户已选择另一救济。模型列为待核查因素，不替任一方确认成立；不建议伪造、补做或违法取得材料。

## 主张分析卡与方案比较

路径卡至少包括假种、地区、程序阶段、用户目标、当前事实状态、最低成立事实、证据缺口、全国基线、地方差异、时效/程序提示、官方来源、专业复核建议和下一步。初步判断使用“信息不足”“有一定支持”“倾向支持”“倾向不支持”，不提供胜率或确定性结论。

当休假权、工资差额和行政待遇可能并存时，方案比较先说明请求对象、责任主体、程序差异、时效和重复获偿风险，再给出合法主位方案与稳健备选。条件相当时可推荐更有利的合法方案；仍依赖地方核验、资格或支付性质时保持条件情景。产假中的生育津贴和单位工资差额必须作为不同组件分别记录，不能因金额较大而自动合并。

## 金额与 amount.calculate

本路由默认不生成精确金额。模型若已将路径明确分流为工资/待遇差额，且事实、期间、基数、已付金额、单位和法律口径均明确，可选择已有的 `wage_difference@1.0.0` 或 `independent_amount_total@1.0.0`，把每个假种、期间和待遇性质作为独立分项；若只知道可能存在待遇差额，使用条件情景或占位，不用计算器判断适用法律。

`wage_difference` 的纯数学为 `max(0, 基数 × 数量 × 倍数 − 已付金额)`；跨月跨年或不同地区规则必须拆分，独立分项先按人民币分 `ROUND_HALF_UP` 舍入再汇总。计算器不得计算“应享几天假”、判断生育津贴与工资差额关系、把未休假统一折现或替模型推荐最大方案。

## 动态核验与降级

地区、假种资格、工资/待遇标准、程序口径、来源过期或冲突、用户要求最新依据以及依赖现行地方规则的高风险定稿触发官方动态核验。核验失败时继续路径分析、证据计划、条件情景和候选材料，说明未核验变量；只有实质依赖易变规则的不可逆外发定稿暂缓，并建议专业复核。

## 交叉影响与重复获偿

- 未休年休假工资单独处理，不进入其他带薪假路由的统一折现。
- 产假中的休假权、生育津贴和单位工资差额是三个可能不同的证明和程序组件；同一支付记录只能在明确的组件中计入。
- 病假工资差额、社保待遇和劳动关系/工资事实可以共享证据，但不自动转化为同一仲裁请求。
- 带薪假待遇与欠薪、加班或解除请求交叉时，模型对照期间和已付项目，排除同一收入的重复获偿。
- 行政处理路径与劳动仲裁/诉讼交叉时，先明确请求对象和可并行范围；路径卡不输出金额或“最优方案”。

## 四类最小行为样本

| 样本 | 事实与模型结果边界 |
| --- | --- |
| 成立样本 | 假种、地区、资格、安排和待遇支付均有支持；给出休假权或待遇差额路径，并列证据和程序下一步。 |
| 不成立样本 | 材料显示不具备假种资格、已完整休完或请求属于另一行政待遇；标记当前不适用/排除，不强行现金化。 |
| 信息不足样本 | 地区、假种资格、单位答复或待遇性质缺失；只给待核验路径和一个补证问题，不生成精确金额。 |
| 事实冲突样本 | 请假记录、单位答复、工资流水或待遇通知互相冲突；分别列休假权/工资差额/行政待遇情景，不自动合并。 |
