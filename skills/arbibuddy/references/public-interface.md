# 公共工具与回复边界

模型负责理解案情、选择问题、分析和起草。三个工具只执行确定性任务：

- [案情档案](model-led-case-archive.md)：创建、读取与原子提交唯一 Markdown 档案。
- [金额计算](amount-calculate.md)：按显式输入做可复核算术。
- [文书生成](document-render.md)：校验锁定要素、生成 DOCX、核对回执和取得可展示文件。

具体输入、错误和恢复方法以各工具参考为准；平台只负责安装、调用、能力观察和文件展示，不另设逐轮对话协议。交付文件的可取得路径可以提供给用户。

## 用户可见边界

公开回复把工具过程转换为业务语言，只保留事实变化、当前问题、风险边界、待核实项和下一步。内部记录或版本、案件编号、命令与协议、输入消费、重试/重放、错误码和实现动作都不属于用户界面；发生失败时只说明用户需要补充的事实、可执行的恢复动作或当前限制。

恢复、验证或测试型会话也只返回业务结果：说明档案是否已从当前工作区继续、事实是否已更新、哪些事项待核实以及下一步。读取路径、版本比较、契约/门禁、网络状态、并发/重放、错误语义和模拟测试动作属于内部过程；未确认地区时不在当前案件中演练或落档地方规则。

恢复-only 回合只允许一次承载公开 `read-current`/`read` 的受管 transport；固定启动前缀属于该调用。成功读取当前档案后立即结束工具调用，不读取其他参考或执行验证；不得把历史更正、恢复路径或核验降级写成用户可见报告，只回到一个业务问题。
